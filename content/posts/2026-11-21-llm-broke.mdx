## LLM出力の壊れたJSONとは

LLM（大規模言語モデル）が生成するJSON形式のデータは、時折壊れてしまうことがあります。具体的には、以下のような問題が発生することがあります。

## 主な機能と使い方

Pythonの標準ライブラリには、`json`モジュールが含まれており、JSONデータの生成や解析を行うことができます。このモジュールを使って、壊れたJSONを修復するための基本的なステップは以下の通りです。

1. **テキストの前処理**: 余分な文字やコメントを削除します。
2. **JSONのパース**: 修復したテキストを`json.loads()`を使ってパースします。
3. **型検証**: パースしたデータの型を検証し、必要に応じてエラーハンドリングを行います。

具体的な実装例は以下のようになります。

```python
import json
import re

def repair_json(broken_json: str) -> dict:
    # 余分なテキストを削除
    clean_json = re.sub(r'^\s*//.*?\n', '', broken_json)  # コメントの削除
    clean_json = clean_json.strip().rstrip(',')  # 末尾カンマの削除

    # JSONパース
    try:
        return json.loads(clean_json)
    except json.JSONDecodeError as e:
        print(f"JSONデコードエラー: {e}")
        return {}

# 使用例
broken_json = "{ 'key': 'value', }"  # 壊れたJSON
repaired_data = repair_json(broken_json)
print(repaired_data)
```

このコードは、壊れたJSONを修復してから解析することを目的としています。
