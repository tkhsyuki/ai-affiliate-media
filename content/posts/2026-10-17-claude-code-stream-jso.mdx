## Claude Code とは

Claude Code は、AI を活用したプログラミング支援ツールで、従来のコーディング作業を効率化するために設計されています。ターミナルでの操作が一般的ですが、最近ではアプリケーションからも利用されるようになっています。特に、社内チャットボットやエディタの拡張、CI スクリプトなどでの活用が注目されています。

## 主な機能と使い方

Claude Code には、以下のような主な機能があります。

1. **プロンプトによる応答**: `claude -p "..."` コマンドを使って、与えられたプロンプトに基づいて AI が応答します。ただし、1 回のプロンプトに対する応答が終わるとプロセスが終了します。
  
2. **連続的な対話**: `--resume` オプションを使うことで、前回の続きから再開できますが、これには再度プロセスを起動し直さなければならず、不便です。

3. **ユーザーへの質問**: Claude が選択肢を提示してユーザーに質問する機能もありますが、プログラムから自動的に答えることは難しいです。

これらの機能を活用するためには、stream-json を使ってデータのストリーミングを行う必要があります。

## おすすめの使い方・活用例

1. **社内チャットボット**: Claude Code を用いて、社内の質問応答システムを構築できます。ユーザーが入力した質問に対して、自動的に Claude Code が応答します。

2. **エディタの拡張**: コードエディタに Claude Code を統合することで、リアルタイムでコードに対するアドバイスを提供します。これにより、コーディング効率が向上します。

3. **CI スクリプト**: CI/CD 環境において、Claude Code を利用してビルドやテストの過程での判断を自動化することができます。これにより、開発者は手動での確認を減らし、効率的に作業を進められます。
