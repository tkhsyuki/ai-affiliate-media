## 主な機能と使い方

2. **物理エンジン**: オブジェクト同士の衝突判定や重力のシミュレーションが可能です。
3. **アニメーション**: オブジェクトの動きをアニメーションとして設定できます。
4. **インタラクティブな要素**: ユーザーの操作に応じたインタラクションを実現できます。

使い方は非常にシンプルで、まずはBabylon.jsのライブラリをインポートし、基本的なシーンを構築することから始めます。以下は、基本的なコードの例です。

```javascript
const canvas = document.getElementById("renderCanvas");
const engine = new BABYLON.Engine(canvas, true);
const scene = new BABYLON.Scene(engine);

// カメラの設定
const camera = new BABYLON.ArcRotateCamera("camera", Math.PI / 2, Math.PI / 2, 5, BABYLON.Vector3.Zero(), scene);
camera.attachControl(canvas, true);

// 環境光の設定
const light = new BABYLON.HemisphericLight("light", new BABYLON.Vector3(0, 1, 0), scene);

// 球体の作成
const sphere = BABYLON.MeshBuilder.CreateSphere("sphere", { diameter: 2 }, scene);

// レンダリングループ
engine.runRenderLoop(() => {
    scene.render();
});
```

このようにして、基本的なシーンを作成し、ゲームに必要な要素を追加していきます。
