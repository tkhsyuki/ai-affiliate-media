## PID制御とは
PID制御とは、Proportional（比例）、Integral（積分）、Derivative（微分）の3つの制御項を使って、目標値に対する誤差を最小化する方法です。これにより、システムを「ちょうどよく」安定させることが可能になります。PID制御は、ロボット工学や自動運転車、温度制御など、さまざまな分野で広く利用されています。

## 主な機能と使い方
PID制御をPythonで実装するためには、まずNumPyライブラリをインストールします。次に、PID制御の各項を計算する関数を作成します。以下は基本的な実装の流れです。

1. **誤差の計算:** 現在の値と目標値の差を求めます。
2. **比例項の計算:** 誤差に比例した値を計算します。
3. **積分項の計算:** 過去の誤差を積分して累積します。
4. **微分項の計算:** 誤差の変化率を求めます。

これらの項を足し合わせることで、制御出力を得ることができます。実際のコードは以下のようになります。

```python
import numpy as np

class PID:
    def __init__(self, Kp, Ki, Kd, dt):
        self.Kp = Kp
        self.Ki = Ki
        self.Kd = Kd
        self.dt = dt
        self.prev_error = 0
        self.integral = 0

    def update(self, setpoint, measured_value):
        error = setpoint - measured_value
        self.integral += error * self.dt
        derivative = (error - self.prev_error) / self.dt
        output = self.Kp * error + self.Ki * self.integral + self.Kd * derivative
        self.prev_error = error
        return output
```

このクラスを使って、目標値に向かって動くロボットの動作をシミュレーションすることができます。
