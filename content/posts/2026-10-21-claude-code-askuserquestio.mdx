## Claude Code とは

Claude Code は、強力なAIツールであり、プログラミングやデータ処理に関する多くの機能を提供します。特に、選択式の質問を通じてユーザーにインタラクティブな体験を提供します。これにより、ユーザーは自身のニーズに合わせた最適な選択を行うことができます。

## 主な機能と使い方

Claude Code の主な機能には、プログラムの自動生成、データ解析、選択式の質問によるインタラクションなどがあります。特に、AskUserQuestion ツールを使用することで、ユーザーは対話形式で AI に具体的な指示を与えることができます。

このツールでは、-p モードを使用して質問に答えることができます。PreToolUse フックが許可された場合、ユーザーは入力を更新して AI に答えを返すことができます。これは通常の対話セッションでも可能で、PermissionRequest フックを使用することで同様の操作ができます。Claude Code 2.1.283 でのテストでは、これがうまく機能しました。
